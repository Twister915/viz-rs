# vis-rs

Put in a .wav file, see this:

![image of vis-rs](./demo.gif)

Set the visualizer colors in `config.yml` to 6-digit hex colors, for example:

```yaml
background_color: "#d6ecfc"
bar_color: "#4f9fd1"
bar_difference_color: "#b9e7ff"
debug_fft_overlay_color: "#5f87a5"
high_water_line:
  color: "#f8fcff"
  fall_acceleration: 2.0
```
